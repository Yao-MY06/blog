## 核心框架：五维度评分法（增加"可变现潜力"）

当一个"新技能冲动"出现时，按以下五个维度评分，每项 1-5 分。

### 五个维度

| 维度 | 1分 | 3分 | 5分 | 权重 |
|------|-----|-----|-----|------|
| **紧急度** | 纯兴趣，没有明确使用场景 | 半年内可能用到 | 现在不学就要错过机会 | 1.2x |
| **职业相关度** | 跟目标岗位/方向完全无关 | 相关但不是核心 | 直接决定能否拿到想要的岗位 | 1.5x |
| **已有基础** | 完全零基础，需要大量前置知识 | 有相关知识可以迁移 | 已经入门，只差深入 | 1.0x |
| **时间成本** | 需要6个月以上系统学习 | 2-3个月可以上手 | 几周就能出成果 | 1.3x |
| **可变现潜力** | 无法直接或间接产生收入 | 可能通过求职变现 | 可直接接单/做产品赚钱 | **1.8x** |

> **为什么可变现潜力权重最高（1.8x）？** 因为你不是在做慈善学技术。一项技能如果最终不能换成钱，那它就是昂贵的爱好——爱好可以保留，但必须在生存技能稳固之后。

### 得分规则

```
原始总分 = 紧急度×1.2 + 职业相关度×1.5 + 已有基础×1.0 + 时间成本×1.3 + 可变现潜力×1.8
加权总分 > 18 分  → 允许进入"02-项目管理"立项（门槛提高，因为多了变现维度）
加权总分 ≤ 18 分  → 直接拒绝 或 放入"冷冻区"72小时后再评估
```

### 变现维度评分指南

| 分值 | 标准 | 举例 |
|------|------|------|
| 1分 | 纯粹的爱好，没有任何变现路径 | 学画画只是为了自己开心 |
| 2分 | 可能有间接价值，但路径很长 | 学Unity为了"有一天"做独立游戏 |
| 3分 | 可以通过求职变现，但需要完整作品集 | 学React为了找前端实习 |
| 4分 | 可以直接接单，市场有明确需求 | 学Next.js做企业官网外包 |
| 5分 | 高需求+高单价，或可以做成产品 | 学AI Agent开发做自动化工具/SaaS |

## 评分案例

### 案例1：学 Blender 建模（第二优先级）

| 维度 | 评分 | 理由 | 加权得分 |
|------|------|------|----------|
| 紧急度 | 2 | 想做游戏资产但不是现在必须 | 2 × 1.2 = **2.4** |
| 职业相关度 | 3 | 全栈岗位不强制要求，但可视化能力加分 | 3 × 1.5 = **4.5** |
| 已有基础 | 2 | 用过一点点，几乎零基础 | 2 × 1.0 = **2.0** |
| 时间成本 | 2 | 需要3-6个月才能做出像样的东西 | 2 × 1.3 = **2.6** |
| 可变现潜力 | 2 | 可接单做3D资产，但市场需求有限且竞争激烈 | 2 × 1.8 = **3.6** |
| **合计** | | | **15.1 / 29** |

**决策：不通过（15.1 < 18）**。Blender 属于第二优先级，在当前阶段不应该立项。
**处理方式**：写入 `03-领域与长期/技能冷冻区.md`，标注"全栈作品集完成后启动"。
**变现备注**：Blender的变现路径主要是接单做3D模型/动画，单价300-3000元不等。但学习曲线陡峭，前6个月很难产出可售卖的作品。建议全栈稳定收入后再考虑。

**处理方式**：拒绝。如果 72 小时后仍然想学，允许读 1 小时入门文档作为娱乐，但不立项。

## 冲动学习冷却期规则

### 规则原文

> **任何新技能冲动，必须等待 72 小时后才允许做出最终决策。**

### 为什么不是24小时？

因为：
- **0-6小时**：多巴胺峰值期，你看什么想学什么的冲动最强
- **6-24小时**：社交媒体的"种草"内容还在脑子里转
- **24-72小时**：如果三天后你还记得这件事，并且觉得它**比手头的事更重要**，那才值得认真评估

### 冷却期操作指南

当你产生"我想学XX"的冲动时：

1. **立即**：把这个想法记入 `00-收件箱`，写一句话"想学XX，因为..."
2. **同一时刻**：**不要**打开任何教程、**不要**买书、**不要**加入付费社群
3. **接下来72小时**：继续做你手头优先级最高的项目
4. **72小时后**：打开这个文件，做五维度评分
5. **评分结果**：
   - >18分 + 还想学 + P0有空位 → 进入待启动
   - ≤18分 或 已经不想学了 → 删掉收件箱里的记录，move on
