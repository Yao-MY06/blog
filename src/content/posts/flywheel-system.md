## 三、四类任务模板 × 当前主线（全栈版）

> 每周任务从"执行层"的全栈路线图中提取，套用"调度层"的四类模板执行。

### 本周任务拆解示例（全栈第3-4周）

| 路线图任务 | 飞轮模板 | 模型层级 | 预算 | 验收标准 |
|-----------|---------|---------|------|---------|
| 学习React组件/State | **模板A：知识拆解** | L1 本地 | ¥0 | 能口述Props/State区别 |
| 做React待办应用 | **模板B：项目组件生成** | L2 API | ¥15 | 代码能跑，逐行能解释 |
| 遇到CORS/编译报错 | **模板C：Bug诊断** | L1→L2 | ¥5 | 同类Bug清单更新 |
| 每周记账数据整理 | **模板D：自动化脚本** | L1 本地 | ¥0 | 脚本实际跑过 |

### 模板A：知识拆解（白天挂机，L1本地跑）

```
触发条件：需要理解一个新概念（React State、Express中间件等）
输入：一篇技术文档/教程章节
Agent任务：
  1. 一句话总结核心概念
  2. 3个"如果不懂这个会踩的坑"
  3. 1段可运行的最小代码示例
  4. 关联到已有知识（你学过的Python/Java）
  5. 输出Obsidian模板格式
输出位置：Agent资产库/01_知识拆解/全栈/[概念名].md
验收标准：能不看原文，用嘴把"3个坑"复述给空气听
```

### 模板B：项目组件生成（晚上跑，L2 API）

```
触发条件：全栈路线图中的"实现XX功能"
输入：具体功能点（如"待办应用的本地存储"）
Agent任务：
  1. 2种技术方案对比（优缺点+适用场景）
  2. 推荐方案并生成完整代码（带注释）
  3. 3个测试用例
  4. 部署注意事项
输出位置：GitHub仓库 + Agent资产库/02_项目孵化/全栈/[功能名]/
验收标准：代码能跑通，你能逐行解释，不是复制粘贴
```

### 模板C：Bug诊断与复盘（按需触发，L1→L2）

```
触发条件：遇到报错/异常行为
输入：报错信息 + 你的尝试记录
Agent任务：
  1. 分析根因（给诊断思路，不是直接给答案）
  2. 给出修复步骤
  3. 生成"同类Bug预防检查清单"
输出位置：Agent资产库/03_Bug库/全栈/[错误类型].md
验收标准：清单加入"编码前必读"，下次同类Bug自己先查
```

### 模板D：自动化脚本（周末批量跑，L1本地）

```
触发条件：发现重复性痛点（每周出现2次以上）
输入：重复任务描述
Agent任务：
  1. 写Python脚本解决
  2. 写使用文档（安装依赖、运行命令）
  3. 写异常处理逻辑
输出位置：本地脚本库 + GitHub + Agent资产库/04_工具脚本/
验收标准：脚本你实际跑过，集成到工作流
```
