> **定位：网上看到值得学的讨论/文章/观点（含交给 AI 润色的稿子），如何进入系统并真正长到自己身上。** 按需使用，不是日常入口；不制造第二个 P0——外部内容最多是知识处理或辅助线，永远不挤占 Java 主线。
> 与姊妹方法的关系：学**陌生概念**用 [AI辅助概念深度学习法](/blog/posts/ai-assisted-deep-learning/)；摄入**别人的讨论观点**（本页）；两者都最终落回 [知识处理 SOP](/blog/posts/knowledge-processing-sop/) 的最小笔记。

## 一、刷到时：只捕获，不打断 P0

在 快速捕获 加一行：

```
- [ ] YYYY-MM-DD | 网上讨论 | 核心观点一句话 | 来源链接
```

当场**不润色、不展开、不深读**。按快速捕获规则每周批量路由，待处理上限 20 条。

## 二、每周路由：复用既有路由表

| 判断 | 去向 |
|------|------|
| 能直接支持 Java 主线或项目 | `02-项目管理/[项目]/参考资料/`，尽快在项目中用 |
| 是系列课/书 | `08-内容源与进度/候选池.md` |
| 单个知识点要深究（3+ 资料/2+ 实验） | `09-主题研究/[主题]/` |
| 单个知识点可直接消化 | 按本 SOP 第三、四步处理 |
| 无明确用途 | 删 |

## 三、处理时：润色稿是素材，不是笔记

这是本 SOP 的核心区别。你手里有 AI 润色稿时：

- **润色稿 = 别人观点 + AI 重写 ≠ 你的理解。** 存润色稿当笔记，存的是收藏，不是知识。
- 正确做法：以原始讨论 + 润色稿为参考资料，按 [知识处理 SOP 第三节](/blog/posts/knowledge-processing-sop/) 写四字段最小笔记——一句话理解 / 一个例子 / 一个易错点 / 来源。必须用自己的话，例子优先来自你自己刚做的验证，不抄润色稿。
- **涉及代码或事实**：按 [AI 使用公约](/blog/posts/ai-usage-convention/) 验证——代码本地跑通，事实查官方文档。网上讨论可能过时或错误，AI 不负责核对事实；投资/医疗/法律类内容只学方法论、不照做，行动前重新查证。

## 四、实践应用：没有这一步 = 白收藏

按"最小实践"原则二选一（或都做）：

1. **非实践类**（思维/观点/方法）：联系一个你**正在发生**的真实问题（当前学习卡点、项目决策、作息问题），写一段「事实 — 主要矛盾 — 下一步行为」。没有这段分析不算读完。
2. **实践类**（工具/技巧/代码）：上手反复做 + 拿反馈，做到"手自己知道下一步"；能落到当前项目里就优先在项目里用。

留痕：在对应文件记一行产出——知识笔记、实验记录、或 输出记录。

## 五、红线

- ❌ 把 AI 润色稿当"我学会了"直接存知识笔记——等于把别人的理解挂自己名下。
- ❌ 因为润色稿写得漂亮就当作已验证——漂亮和正确是两回事。
- ❌ 为摄入内容新开 P0 或挤占主线块——它走捕获→周路由的既有通道。
- ✅ 记住：收藏/润色本身 ≠ 学习。只有再次被调用、并在题目或项目里验证过，才算你的。

> 一句话收口：**润色帮你"读得懂"，最小实践帮你"长在自己身上"。没有第四步，润色稿只是收藏夹里又多了一篇好文章。**
