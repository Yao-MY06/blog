## 一、代码与开发

### VS Code（必选）

**为什么选它**：免费、插件生态最全、教程最多、就业后也在用。

**最小配置步骤（3步搞定）**：

```bash
# 第1步：安装以下插件（Extensions面板搜索）
- ESLint          # 代码规范检查
- Prettier        # 代码格式化
- GitLens         # Git历史查看
- Live Server     # 本地实时预览HTML
- Tailwind CSS IntelliSense  # Tailwind自动补全

# 第2步：打开设置（Ctrl+,），搜索并配置：
"editor.formatOnSave": true
"editor.defaultFormatter": "esbenp.prettier-vscode"
"files.autoSave": "afterDelay"

# 第3步：终端执行，配置Git身份（必须做）
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

### Git + GitHub（必选）

**为什么选它**：版本控制是程序员的必备技能，GitHub绿墙是你学习的可视化证据。

**最小配置步骤（3步搞定）**：

```bash
# 第1步：注册 GitHub 账号，创建第一个仓库
# 第2步：本地生成SSH密钥
cd ~
ssh-keygen -t ed25519 -C "你的邮箱"
cat ~/.ssh/id_ed25519.pub  # 复制输出内容

# 第3步：粘贴到 GitHub → Settings → SSH and GPG keys → New SSH Key
# 测试连接
ssh -T git@github.com  # 看到 Hi xxx! 即成功
```

**Git日常命令速查**（贴在显示器旁边）：

```bash
git add .                          # 添加所有改动
git commit -m "描述这次提交"        # 提交
git push origin main              # 推送到GitHub
git pull                          # 拉取最新代码
git log --oneline                 # 查看提交历史
```

## 二、学习环境控制

### Cold Turkey Blocker（Windows/Mac）

**为什么选它**：比意志力可靠100倍。一旦锁定，除非你重启电脑，否则打不开黑名单网站。

**最小配置步骤（3步搞定）**：

```
第1步：下载安装 https://getcoldturkey.com/（免费版够用）

第2步：创建"学习模式"Block，添加以下到黑名单：
- bilibili.com
- douyin.com
- weibo.com
- xiaohongshu.com
- twitter.com
- reddit.com
- 所有游戏启动器的域名（Steam、Epic等）

第3步：设置定时启动
- 周一至周五 08:00-12:00 自动启动
- 周一至周五 14:00-18:00 自动启动
- 周六 09:00-12:00 自动启动
```

**备用方案（如果Cold Turkey不可用）**：

```
# 用hosts文件手动屏蔽（Windows/Mac/Linux通用）
# 以管理员身份编辑：
# Windows: C:\Windows\System32\drivers\etc\hosts
# Mac/Linux: /etc/hosts

# 在末尾添加：
127.0.0.1 bilibili.com
127.0.0.1 www.bilibili.com
127.0.0.1 douyin.com
127.0.0.1 www.douyin.com
127.0.0.1 weibo.com
127.0.0.1 www.weibo.com
127.0.0.1 xiaohongshu.com
127.0.0.1 www.xiaohongshu.com
127.0.0.1 twitter.com
127.0.0.1 www.twitter.com
127.0.0.1 reddit.com
127.0.0.1 www.reddit.com

# 保存后刷新DNS缓存
# Windows: ipconfig /flushdns
# Mac: sudo killall -HUP mDNSResponder
```

### Forest（手机端）

**为什么选它**：游戏化专注，种树机制提供即时正反馈。比系统自带专注模式更有成就感。

**最小配置步骤**：

```
第1步：App Store/应用商店搜索"Forest"，下载安装

第2步：设置：
- 种植时长：45分钟（默认25分钟太短，进入心流需要时间）
- 深度专注模式：开启（离开App树会枯死）
- 白名单：只允许电话、短信、相机

第3步：放置手机策略：
- 学习时手机放在：床上/衣柜里/另一个房间
- Forest种树时：屏幕朝下放在桌上（不要看）
- 允许查看手机的唯一时机：种树完成后休息5分钟
```

### 白噪音歌单

**为什么需要**：安静的环境反而容易走神。白噪音提供稳定的听觉背景，屏蔽突发噪音。

**推荐（ Spotify / Apple Music / 网易云 搜索即可）**：

| 场景 | 歌单关键词 | 特点 |
|------|-----------|------|
| 写代码 | "Lofi Hip Hop" / "Coding Music" | 无歌词，节奏稳定 |
| 阅读/笔记 | "Rain Sounds" / "Cafe Ambience" | 模拟环境音 |
| 深度思考 | "Brown Noise" / "White Noise" | 纯噪音，最不容易分心 |
| 提神 | "Video Game OST" / "Epic Music" | 节奏稍快，适合下午犯困时 |

**最小配置**：选一个歌单，收藏，以后每次学习直接播放。**不要每次花时间选音乐**。

## 三、笔记与知识管理

### Obsidian（推荐）

**为什么选它**：本地存储（你的笔记永远属于你）、双向链接（卡片笔记法的最佳实践）、免费、Markdown格式通用。

**最小配置步骤（3步搞定）**：

```
第1步：下载 https://obsidian.md/，安装

第2步：创建新Vault（知识库），设置：
- 新建笔记存放路径：04-知识笔记/
- 开启"每日笔记"插件，存放路径：01-日记与周期/
- 开启"模板"插件

第3步：创建两个核心模板：
  - 项目笔记模板（用于02-项目管理）
  - 知识卡片模板（用于04-知识笔记）
```

**Obsidian项目笔记模板**（保存为 `模板/项目笔记.md`）：

```markdown
---
项目名：{{title}}
创建日期：{{date}}
优先级：P0/P1/P2
状态：进行中/暂停/已完成
---

## 目标
（一句话说清楚这个项目要产出什么）

## 任务拆解
- [ ] 任务1
- [ ] 任务2
- [ ] 任务3

## 进度记录
| 日期 | 做了什么 | 用时 |
|------|----------|------|
| {{date}} | 项目启动 | - |

## 相关笔记
（用 笔记名 链接相关知识卡片）

## 复盘
（项目完成后填写）
- 做得好的：
- 做得不好的：
- 下次改进：
```

**Obsidian知识卡片模板**（保存为 `模板/知识卡片.md`）：

```markdown
---
标题：{{title}}
创建日期：{{date}}
标签：#待分类
来源：
---

## 核心概念
（用自己的话写，不要复制粘贴）

## 为什么重要

## 与我已知知识的联系
（这是卡片笔记法的核心：新旧知识建立链接）

## 具体例子/代码

## 待解决的问题

## 相关卡片
- 相关卡片1
- 相关卡片2
```

### Notion（备选）

如果你 Obsidian 用不惯，选 Notion。优缺点对比：

| 特性 | Obsidian | Notion |
|------|----------|--------|
| 数据归属 | 本地文件，永远属于你 | 云端，有服务终止风险 |
| 网络依赖 | 无网络也能用 | 必须联网 |
| 数据库功能 | 需插件 | 原生强大 |
| 协作分享 | 需额外配置 | 一键分享 |
| 价格 | 免费够用 | 免费够用 |

**建议**：个人知识管理用 Obsidian，需要协作/分享时用 Notion。

## 四、项目管理

### GitHub Projects（推荐）

**为什么选它**：跟代码仓库天然集成，一个页面看到所有项目进度，免费。

**最小配置步骤（3步搞定）**：

```
第1步：打开 GitHub → 你的个人主页 → Projects → New Project

第2步：创建看板，设置4列：
  - Backlog（待安排）
  - In Progress（进行中，同时不超过2项）
  - Review（待检查/待完善）
  - Done（已完成）

第3步：把当前所有项目作为卡片加入：
  - 全栈个人主页（In Progress）
  - 课程XX作业（In Progress）
  - 待办应用（Backlog）
```

### 备选：物理看板

如果你更喜欢实体的感觉：

```
材料：一块软木板 + 便利贴4种颜色
列名：待做 / 进行中 / 卡住 / 完成
规则：
  - 黄色便利贴 = P0 第一优先级
  - 橙色便利贴 = P1 第二优先级
  - 蓝色便利贴 = P2 恢复性活动
  - 红色便利贴 = 紧急/今天必须完成
限制："进行中"列同时不超过2张便利贴
```

## 五、时间追踪

### Toggl Track（推荐）

**为什么选它**：免费、跨平台、一键开始/停止追踪。数据会让你震惊——你会发现自己"觉得学了一整天"其实只有3小时。

**最小配置步骤（3步搞定）**：

```
第1步：注册 https://toggl.com/track/，安装浏览器插件和手机App

第2步：创建项目分类：
  - 全栈学习（#1优先级）
  - 课程作业
  - 阅读/笔记
  - 恢复性活动（画画/游戏等）
  - 其他

第3步：每次开始学习前点一下开始，结束后点停止
      晚上查看"今天实际学了多久"
```

### 物理番茄钟（强烈建议配合APP使用）

```
推荐：机械番茄钟（淘宝20-30元）或厨房定时器
为什么用物理的：比手机App更有仪式感，放在桌上是视觉提醒
使用规则：
  - 一个番茄钟 = 45分钟专注 + 10分钟休息
  - 每4个番茄钟 = 大休息30分钟
  - 番茄钟响之前：不能看手机、不能打开娱乐网站、不能离开座位
  - 完成后在纸上画一个"正"字——物理计数提供正反馈
```

**每日番茄钟追踪表**（打印出来贴在墙上）：

```
日期：________

目标番茄数：8    实际完成：____

| 时段 | 内容 | 番茄数 | 完成情况 |
|------|------|--------|----------|
| 上午 |      |        |          |
| 下午 |      |        |          |
| 晚上 |      |        |          |

本周累计：____ / 目标 ____
```

```bash
# 4. 测试：浏览器访问 bilibili.com，应该显示"无法访问"
```

#### 方案C：路由器定时断网（最物理）

```
操作步骤：
1. 登录路由器管理后台（通常是 192.168.1.1 或 192.168.0.1）
2. 找到"家长控制"或"上网控制"功能
3. 添加你的设备MAC地址，设置：
   - 周一至周五：23:00 - 07:00 禁止上网
   - 周六至周日：00:00 - 08:00 禁止上网
4. 保存设置

效果：到点自动断网，强制睡觉。早上恢复，倒逼早起。
```

### 手机隔离方案

#### 物理隔离（最推荐）

| 场景 | 手机位置 | 额外措施 |
|------|----------|----------|
| 在图书馆/教室学习 | 放在书包里，书包放在视线外 | 开启Forest种树45分钟 |
| 在宿舍学习 | 放在床上，屏幕朝下 | 用室友监督： "如果我学习时碰手机，请你骂我" |
| 睡前 | 放在书桌，不在床头 | 用闹钟代替手机闹钟（买20块的物理闹钟） |
| 需要手机查资料时 | 拿过来查完立即放回去 | 不要"顺便看一眼消息" |

#### App锁机方案

```
安卓推荐：
- 专注海洋（Forest安卓版）
- 禅定空间（强制定时锁机，到时间才能解锁）
- 远离手机（锁机后只能接电话）

iOS推荐：
- 系统自带"屏幕使用时间" → App限额
  设置路径：设置 → 屏幕使用时间 → App限额 → 添加限额
  - B站/抖音/微博：每天 30 分钟
  - 游戏类App：每天 0 分钟（完全禁止）
- Forest（iOS版）

配置建议：
1. 所有娱乐App限额 30分钟/天
2. 限额用完后需要输入密码——让室友帮你设密码
3. 睡觉前1小时开启"停用时间"，只有电话可用
```

## 七、工具选择速查表

| 你的需求 | 推荐工具 | 替代方案 | 绝对不要用 |

```
□ 手机放在_______（不在手边）

确认完毕，开始学习。 distractions can wait, your future cannot.
```
