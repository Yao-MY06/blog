## 第一步：遇到想学的东西，先问一句

```
这个知识，是靠"看和听"就能会，还是必须"动手做"才能会？

如果是"看和听"就能会（比如：知道秦朝灭亡于公元前207年）
    → 走【非实践路线】

如果是"必须做了才有感觉"（比如：学会骑自行车不摔倒）
    → 走【实践路线】

不确定？（比如：学做红烧肉）
    → 默认走实践路线，因为"所有知识归根结底来源于实践"
```

## 第二步：非实践知识学习流程（理论/间接经验）

> 目标：快速吃透别人的实践总结，然后逼自己至少做一次最小实践

### 阶段1：AI快速拆解（30分钟-1小时）

**你做的**：把想学的东西丢给AI

**AI做的**：
1. **一句话说清**——这玩意到底是啥
2. **三张图讲明白**——用类比/图示解释核心概念（比如：用"水管"类比"电路"）
3. **三个坑预警**——学这个最容易在哪摔跤
4. **关联已有知识**——跟你已知的什么东西像？（比如：学React State → 跟你学过的变量赋值像）
5. **最小实践方案**——理论归理论，不做等于零，给你一个"10分钟就能做完的验证实验"

**产出物**：一张A4纸能写完的笔记，贴墙上

**验收标准**：不看原文，你能用嘴给空气讲清楚这玩意是干嘛的

---

### 阶段2：最小实践（必须做，不做等于白学）

> 核心原则：非实践知识只是别人实践完传给你的，你不亲自做一次，永远是别人的知识

**操作**：

| 学的知识 | 最小实践例子 |
|---------|------------|
| 物理学牛顿定律 | 拿手机计算器+小球滚斜坡验证一下 |
| 历史事件（赤壁之战） | 在白纸上画出时间线+各方兵力，讲给朋友听 |
| 经济学供需关系 | 去闲鱼观察一个商品的价格波动，套供需理论 |
| 心理学（沉没成本） | 回想自己最近一次的"舍不得退的烂尾游戏"，套理论分析 |
| 编程概念（闭包） | 手写5行代码跑通，改改参数看效果 |
| 哲学理论（唯物辩证法） | 拿自己"学编程遇到困难"这件事，用辩证法分析一遍 |

**AI辅助**：
- 实践前：帮你设计"最小实验"
- 实践中：卡住时问它
- 实践后：帮你复盘"理论和实际差在哪"

**验收标准**：做完之后你心里默念"哦原来是这样"，而不是"好像懂了"

---

### 阶段3：存进知识库（5分钟）

**记录格式**：

```
知识名：__________
类型：非实践知识
来源：哪本书/哪个视频/谁讲的
一句话总结：__________
最小实践做了什么：__________
做完之后的体感（重要）：__________
跟哪些已有知识挂钩：__________
```

**重点**：必须写"体感"，不能只抄定义。体感是你的，定义是别人的。

## 第三步：实践知识学习流程（经验/体感）

> 目标：大量重复+有反馈，AI当教练，你做运动员

### 阶段1：开干之前（AI帮你定规矩）

**你做的**：告诉AI你要做什么，让它给框架

**AI做的**：
1. **给步骤清单**——先干啥、后干啥，别一上来就乱做
2. **给观察指标**——做到什么程度算"好"，什么现象说明"坏了"
3. **给安全边界**——哪些错误是学费，哪些错误是灾难（比如：做菜糊了是学费，油锅着火是灾难）

**产出物**：一张步骤清单，打印出来贴旁边

---

### 阶段2：反复做（你自己来，AI看着）

**核心**：做，记录，复盘，再做

**循环**：

```
第1遍：做 → 录视频/拍照/写记录 → 让AI看 → 给反馈
    ↓
第2遍：带着反馈做 → 再录 → 再让AI看 → 对比进步
    ↓
第3遍：做 → 自己感觉哪里不顺 → 问AI怎么优化
    ↓
第N遍：做到"不用想就知道下一步" → 成了
```

**AI当教练的用法**：

| 你做什么 | AI做什么 |
|---------|---------|
| 做饭炒糊了 | 分析糊的原因：油温太高？食材有水？锅没烧热？ |
| 骑车摔了 | 分析摔的姿势：重心偏了？刹车太急？速度太慢？ |
| 编程Bug | 不是直接给答案，是问"你改了这个变量之后，预期是什么？实际是什么？" |
| 打篮球投不进 | 录下来给AI看姿势，对比标准动作 |
| 写博客没人看 | 把文章+数据丢给AI，分析标题/开头/结构哪里不对 |

**关键**：AI不给标准答案，它帮你"看见自己没注意到的东西"

---

### 阶段3：形成体感（量变到质变）

**标志**：
- 不再想"下一步该干嘛"，手自己就知道
- 出了问题能自己诊断"这次跟上次哪里不一样"
- 能教别人了（能教才是真会）

**记录格式**：

```
技能名：__________
类型：实践知识
做了多少次：__________
踩过的坑：1.___ 2.___ 3.___
现在的手感（用身体描述，不要抄书）：
  - 油温七成热的时候，油面微微冒烟，手放上方10cm能感觉到热
  - 自行车快倒的时候，不是往倒的方向躲，是往倒的方向压把
教别人的话我会这么说：__________
```

**重点**：体感必须用"身体语言"描述，不能是书本上的定义。

## 第四步：AI辅助的使用红线

```
非实践知识学习：
  ✅ 让AI拆解概念、给类比、出测试题
  ✅ 让AI帮你设计"最小实践"
  ❌ 让AI代写实践报告（你自己做了才有体感）
  ❌ 跳过最小实践直接存笔记（存的是垃圾）

实践知识学习：
  ✅ 让AI当教练看录像、给反馈
  ✅ 让AI帮你分析"这次和上次差在哪"
  ❌ 让AI替你做（炒菜AI不能替你尝）
  ❌ 只看AI的理论指导不动手（看一万遍视频也不会骑车）
```

## 第五步：杂学管理（怎么不乱的）

### 你的"杂学篮子"

准备一个清单，随时丢进去：

```
我想学但还没开始的杂七杂八：
□ ________  类型：实践/非实践  优先级：现在/以后  来源：哪里看到的
□ ________  类型：实践/非实践  优先级：现在/以后  来源：哪里看到的
□ ________  类型：实践/非实践  优先级：现在/以后  来源：哪里看到的
```

**规则**：
- 篮子最多放10个，满了必须完成一个才能加新的
- 正在学的最多2个，一个主赛道（跟你主线相关），一个纯兴趣
- 每完成一个，打勾，写一句话收获

### 月度杂学安排

```

每天 20 分钟杂学槽（标准日 18:50–19:10，周一 18:45–19:05），一句话输出

安排策略：
  - 周一/三/五：读《实践论》《矛盾论》并联系一个真实问题
  - 周二/四/六：投资概念定义或模拟/数据练习

      但主线学习中遇到的"衍生兴趣"可以丢进篮子排队
```

## 第六步：一句话总结

> **非实践知识**：先让AI帮你拆明白 → 必须做一次最小实践 → 记录体感
> **实践知识**：让AI当教练定规矩 → 自己反复做拿反馈 → 直到形成身体记忆
> 
> **终极检验**：你能不能用一句话教一个完全不懂的人？能，就是真会了。

## 当前双轨的最小实践

### 《实践论》《矛盾论》

每次只读一个小段落，随后选择一个正在发生的真实问题（例如拖延、刷短视频、学习卡点或关系冲突），写一段：事实是什么、主要矛盾是什么、下一步行为是什么。没有这段分析，不把阅读记为完成。

### 投资基础

每次只学一个概念，写出自己的定义，再完成一个模拟或数据动作。前两阶段只做防骗、概念、模拟和 Python 数据项目，不开户跟单、不加入荐股群、不碰杠杆；具体边界见 投资学习与安全边界。

当前周期最多保留这两个主题，当前活跃杂学最多两个，不再启动第三个杂学主题；周日不安排杂学，已有输出也留到周一处理，不用新内容逃避主线。
