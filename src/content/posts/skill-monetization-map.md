## 二、各技能详细变现路径

### P0 第一优先级：全栈开发（React + Node.js + Next.js）

**变现阶段路线图**：

```
第4周（React基础完成）
    │
    ├──→ 静态页面接单（500-1500元）
    │     渠道：朋友圈/校友群/猪八戒
    │     案例：个人博客、企业展示页、活动落地页
    │
第8周（全栈整合完成）
    │
    ├──→ 全栈小应用接单（3000-8000元）
    │     渠道：码市/程序员客栈/即刻
    │     案例：待办应用、记账工具、图书管理、预约系统
    │
第12周（Next.js+TypeScript完成）
    │
    ├──→ 企业级项目（8000-3万元）
    │     渠道：猪八戒/老客户推荐/独立品牌
    │     案例：电商站、SaaS MVP、内容管理系统
    │
第16周（作品集完成）
    │
    ├──→ 求职实习（月薪3K-8K）
    │     渠道：Boss直聘/实习僧/校招
    │     目标：大厂/中厂前端/全栈岗位
    │
    └──→ 稳定接单（月均3000-1万）
          渠道：回头客+推荐+平台
          目标：建立3-5个长期客户
```

**定价策略（按项目规模）**：

| 项目类型 | 工时 | 报价范围 | 适用阶段 |
|----------|------|----------|----------|
| 静态展示页（3-5页） | 8-15h | 1500-4000元 | 第4-8周 |
| 简单交互应用（CRUD） | 20-40h | 4000-1万元 | 第8-12周 |
| 企业官网（10页+后台） | 40-80h | 1万-3万元 | 第12-16周 |
| SaaS MVP | 80-200h | 3万-10万元 | 第16周后 |

## 六、关键原则

### 原则1：先求生存，再求优化
前期不要挑单。500元的小单也要接，目的是：
1. 积累第一个客户
2. 获得第一条好评
3. 跑通"接单→开发→交付→收款"的完整流程
4. 建立信心："我的技能确实能换钱"

### 原则2：时薪比总价更重要
一个报价1万的项目如果要做100小时，时薪只有100元。
一个报价3000的项目如果做10小时，时薪300元。
**选择后者。**

### 原则3：客户质量比客户数量更重要
一个好的长期客户（每季度给你1-2单）胜过10个一次性客户。
维护老客户的成本是获取新客户的1/5。

### 原则4：技术深度决定定价天花板
只会React → 单价上限1万
React+Next.js+Node+部署+性能优化 → 单价上限5万
React+Next.js+Node+AI工具+产品思维 → 单价无上限
